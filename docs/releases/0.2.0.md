## Anime Sama.to Desktop 0.2.0 — Aperçu / Preview

### Français

Cette version mettait l’app à jour pour anime-sama.to, corrigeait les erreurs de
chargement affichées à tort comme des erreurs 500, et ajoutait les actions pour
réessayer ainsi que des corrections de réglages.

Les téléchargements portent maintenant des noms plus simples. Les fichiers de
l’application et son code source sont conservés tels qu’ils ont été publiés.
Après extraction du ZIP, ouvre l’exécutable du dossier.

Merci à [AlexAnimateMp4](https://github.com/AlexAnimateMp4/anime-sama-fr-desktop)
pour l’app d’origine et à [raphael-as](https://github.com/raphael-as/anime-sama-fr-desktop)
pour son travail sur le projet. Licence MPL-2.0.

### English

This version updated the app for anime-sama.to, fixed loading failures being
shown as HTTP 500, and added retry actions and settings fixes.

Downloads now have simpler names. The app files and source are preserved as
originally published. After extracting the ZIP, open the executable in its folder.

Thanks to [AlexAnimateMp4](https://github.com/AlexAnimateMp4/anime-sama-fr-desktop)
for the original app and [raphael-as](https://github.com/raphael-as/anime-sama-fr-desktop)
for his work on the project. MPL-2.0.
