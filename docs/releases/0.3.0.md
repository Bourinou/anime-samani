# Anime Samani 0.3.0 — Aperçu / Preview

## Français

La première version sous le nom Anime Samani.

- Nouvelle interface avec les logos de Samani et une intro au démarrage.
- Thèmes, fonds image ou vidéo, flou et transparence.
- Favoris, pages récentes, accès rapide et mode cinéma.
- Français et anglais dans l’app.
- Nouvelle présence Discord avec le titre, l’épisode et des réglages de confidentialité.

Pour Windows 10/11, 64 bits : Setup, Portable ou ZIP. Version non signée et encore
en aperçu ; la lecture sur le site et une vraie session Discord restent à vérifier
sur ton PC.

Fait avec ❤️. Merci à [AlexAnimateMp4](https://github.com/AlexAnimateMp4/anime-sama-fr-desktop)
pour l’app d’origine et à [raphael-as](https://github.com/raphael-as/anime-sama-fr-desktop)
pour son travail dessus.

## English

The first release under the Anime Samani name.

- New interface with Samani’s logos and a startup intro.
- Themes, image or video backgrounds, blur and transparency.
- Favorites, recent pages, quick access and cinema mode.
- French and English in the app.
- New Discord presence with title, episode and privacy controls.

For 64-bit Windows 10/11: Setup, Portable or ZIP. This unsigned preview still needs
live website playback and a real Discord session checked on your PC.
